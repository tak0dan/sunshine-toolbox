# Changelog

All notable changes to Sunshine Toolbox are documented here. The format is based on
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [1.0.0] - 2026-11-20

### Added

- Initial Sunshine OS release, forked from Garuda Toolbox 6.3.0.
- Sunshine branding throughout: name, logo, icons, themes, terminal palette and URLs.
- Local Sunshine UI primitives and four Sunshine themes (Noon, Ember, Dusk, Midnight).
- All system actions rewired to the Sunshine OS command suite (`sunshine-update`,
  `sunshine-doctor`, `sunshine-info`, `sunshine-rescue`, `sunshine-gaming`, …).
- Sunshine launcher, desktop entry, polkit policy and Arch `PKGBUILD`.
- GitHub Actions build workflow.

### Changed

- Replaced upstream Garuda component libraries with self-contained Sunshine modules.
- Updated all package metadata, documentation and CI configuration for the new repository.
